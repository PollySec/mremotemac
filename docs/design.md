# Design system

mRemoteMac uses one colour system, "Graphite + Indigo": a cool graphite neutral ramp (hue 255°) for every surface,
border and text tone, and a single indigo accent (hue 268°) reserved for selection, focus and the primary action.
Status colours are desaturated so they never compete with the accent. All tokens live in `src/MRemoteMac/App.axaml`
as theme dictionaries (`Light` / `Dark`) and are referenced through `DynamicResource` everywhere.

## Principles

- One accent, used sparingly: selection, focus ring, primary button, active tab indicator. Nothing else is blue.
- Tinted neutrals, low chroma. Hierarchy comes from tone (window < sidebar < content card), not from shadows.
- Hairline borders one or two ramp steps from their background; never black or white.
- Every text/background pair meets WCAG AA (4.5:1 text, 3:1 UI). Primary text is not pure black/white.
- Density for a working tool: 13 px body, 12 px grid, 11 px semibold uppercase section titles, 24 px rows.
- Radii: 5–6 px controls, 4 px list selection, 6 px panel cards, 8 px menus.

## Icons

Interface icons are [Lucide](https://lucide.dev) (ISC license), converted to stroked path geometry at build time
(`src/MRemoteMac/Converters/LucideData.cs`, generated by `tools/convert-lucide.py`) and rendered by the `Icon`
control with the current foreground brush, so they stay crisp on Retina and follow the theme. mRemoteNG's
connection icon names (`Domain Controller`, `File Server`, …) are kept in the file format and mapped to Lucide
glyphs in `Converters/IconNames`.

## App icon

Squircle on Apple's 1024 px grid with the accent gradient `#688BF3 → #4464D3 → #2F4ABA`, a white display glyph
with session tabs, and a `#69C27E` "connected" dot. It is drawn procedurally by `Services/IconRenderer.cs`
(`MRM_RENDER_ICON=<png>` in a debug build) and packaged into `.icns` by `packaging/make-app.sh`.
